# 领域 Agent 平台需求规格

状态：首版工程交付，现场部署与业务验收待完成。本文记录用户批准的首版范围，具体完成情况见路线图与验证记录。

## 产品范围

单组织、100 人以内、10 个并发执行任务；独立账号；管理员管理 Agent，成员浏览获授权的已发布 Agent。Python/FastAPI、LangGraph、React/TypeScript，PostgreSQL/pgvector、Celery/Redis，Docker Compose 部署。首版不提供多租户、SSO、自建 Agent、工作流画布、跨会话长期记忆或任意代码执行。

## 功能

- FR-01：管理员创建、批量导入、停用账号，重置密码，维护用户组；分别授权 Agent 和工具，不开放注册。
- FR-02：成员搜索、查看 Agent 业务介绍、示例问题并发起会话。
- FR-03：多轮、流式、历史、取消、删除与反馈；每会话一个活动任务。
- FR-04：文本 PDF、DOCX、TXT、Markdown、CSV、XLSX，状态及错误可见；不执行宏，不支持扫描 OCR、加密文档。读取与总结不等于可靠代码计算。
- FR-05：Agent 展示信息、提示词、模型参数、工具白名单、知识库、运行限制；草稿、调试、发布、停用、回滚。
- FR-06：对话与嵌入模型独立配置，兼容 OpenAI 协议，测试连接和所需能力。
- FR-07：知识库上传、更新、删除、异步解析/切分/嵌入/索引，重试、检索测试与来源定位。
- FR-08：远程 MCP Streamable HTTP 与 HTTP 工具，参数规则、凭证、执行策略、超时、用户组；不启动 stdio 进程。
- FR-09：用量、时延、错误、反馈、配置和执行审计，不提供管理员浏览成员对话全文。
- FR-10：本地 Git、公开 GitHub、AGENTS、README、锁文件、迁移、Compose、CI 和手动 GHCR 发布。

## 强制数据边界

成员 DTO 使用白名单，不泄露或允许覆盖模型标识、提示词、工具定义、知识库配置、连接端点、凭证及原始轨迹。用户只能访问自己的会话、附件、事件、确认、引用。附件仅属于所在会话，不进入共享知识库。知识库按 Agent 授权，首版没有内部文档级权限。引用只暴露授权片段、标题和位置。

密钥加密存储，不进入模型上下文；调用时由适配器注入，错误和审计脱敏。配置保密不以提示词约束替代服务端访问控制。每次运行锁定已发布配置快照；发布、回滚影响下一运行。停用、撤权在启动、恢复、工具执行前再次校验。

## 工具副作用

工具 effect 为 read/write，policy 为 auto/confirm；新写工具默认 confirm，管理员可改为 auto并记录审计。组织服务凭证调用，上游约束服务账号的数据范围，不继承成员个人业务身份。

权限校验→参数验证→固定调用计划→必要时用户确认→唯一调用账本→执行→记录结果。确认绑定原始调用与参数摘要，参数变化失效。拒绝/超时不执行。写入上游支持幂等键时复用同一键重试；可能已提交但不能确定的结果进入 outcome_unknown，不盲目重试，也不宣称失败或成功。管理员可以核实并记录处置。取消不能撤销已提交操作。

## 运行与默认值

状态 queued/running/awaiting_confirmation/completed/failed/cancelled/outcome_unknown。等待确认释放工作进程；重连不创建新任务。全局 10 执行、成员 2 执行，单运行最多 20 轮、300 秒（不含确认等待）；确认 600 秒。附件每个 20 MiB、每会话 5 个。会话保留至用户删除，级联删除附件、向量、检查点；调试日志 30 天、脱敏审计 180 天；每日备份保留 7 天。

## 工程与发布

本地路径 E:\project\ai\vibeDomainAgent；公开 GitHub compcj/vibe-domain-agent，main；公开镜像 ghcr.io/compcj/vibe-domain-agent，linux/amd64。前后端合一镜像，API 与 Worker 使用相同 digest、不同命令，非 root，健康检查和持久化卷。Nginx、Postgres/pgvector、Redis 独立服务。

发布工作流只有 workflow_dispatch，从 main 最新 SHA 构建并固定代码；锁依赖→测试→构建→临时 DB/Redis 冒烟→使用 GITHUB_TOKEN 发布 sha-<完整 SHA>→按 digest 拉取验证→main 未前进才推广 latest。SHA 标签不覆盖，重复执行复用验证过的镜像。仓库级并发组串行化发布；action 固定完整 SHA，contents:read/packages:write；失败不更新 latest。首次设 package public并匿名验证。push/PR/Release 不发布。

## 验收

端到端配置/发布/问答/引用/工具/回滚；跨成员访问与配置篡改全部拒绝；撤权/过期/拒绝/参数变化不能误执行；重复确认、重投、重启不重复写入；文档删除后不检索；断线恢复；健康部署、迁移、备份恢复、镜像升级和数据库兼容回滚。模拟服务下10并发持续30分钟，错误率<1%、无串用和重复写入。每试点 Agent 30业务案例，业务认可≥85%，权限和写入控制100%通过。真实业务验收需业务负责人，不能用单元测试代替。
